## Resumen

Las **integraciones** conectan Zink ERP con servicios externos: facturación electrónica nativa con **ARCA**, cobros con **Mercado Pago**, tiendas online con **WooCommerce** y otros servicios que se habiliten para tu organización.

No tenés que programar nada: seguís un **asistente** o completás los datos que pide cada servicio. Esta sección está pensada para quienes administran la organización y habilitan esos vínculos.

## Antes de empezar

- Necesitás permisos para entrar a **Preferencias** y a la pestaña **Integraciones**.
- Tené a mano los datos o la cuenta del servicio que vas a conectar (por ejemplo, el punto de venta de ARCA o la cuenta de Mercado Pago).

## Procedimiento

### Dónde se configuran

1. Entrá a **Preferencias**.
2. Abrí la pestaña **Integraciones**.
3. En la columna izquierda ves los **servicios disponibles** para tu organización.
4. El **tilde verde** junto a un servicio indica que el alta quedó registrada.
5. Tocá **Gestionar** para abrir el asistente del servicio (formulario, redirección para autorizar o pasos guiados).

Antes de abrir el asistente, la pantalla puede mostrar una **guía resumida** del servicio con pasos, plazos y enlaces útiles.

### Facturación electrónica

La facturación electrónica se configura en **[ARCA](/integraciones/arca)**, desde **Preferencias → Integraciones**. Es la integración nativa para emitir comprobantes electrónicos desde Zink ERP.

## Si algo sale mal

- Si el problema es **dentro de Zink ERP** (no podés completar un paso o ves un mensaje de error), escribinos a soporte.
- Si el problema es **del servicio externo** (Mercado Pago, ARCA, WordPress, etc.), revisá primero sus canales oficiales: estado del servicio, ayuda y términos.
