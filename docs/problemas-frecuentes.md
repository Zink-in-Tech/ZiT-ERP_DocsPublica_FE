## Resumen

Esta página reúne síntomas generales que pueden aparecer en cualquier módulo de ZinkERP y dónde conviene revisar primero.

---

## Tabla rápida

| Síntoma | Posible causa | Dónde revisar |
|---------|---------------|---------------|
| No puedo iniciar sesión | Contraseña incorrecta, usuario inactivo o problema de acceso | Administrador interno, [Perfil de usuario](./administracion/perfil-usuario.md) si ya accediste |
| No veo un menú | Perfil sin permisos o módulo no habilitado | [Perfiles](./administracion/perfiles.md) |
| Los datos no coinciden | Filtros, organización activa o fecha incorrecta | Selector de organización, filtros de pantalla, [Informes](./informes/informes.md) |
| La página carga lento | Conexión, volumen de datos o filtros amplios | Reducí rango de fechas y consultá soporte si persiste |
| No sé dónde hacer una tarea | El proceso pertenece a otro módulo | [Introducción](./intro.md), [Primeros pasos](./primeros-pasos.md) |
| No aparece una integración | Servicio no habilitado, permisos o organización incorrecta | [Problemas frecuentes de integraciones](./integraciones/problemas-frecuentes.md) |
| El stock no coincide | Compra, venta, inventario o toma pendiente | [Inventario](./inventario/inventario.md) |
| La caja no cierra | Medio de pago incorrecto, cuenta corriente o caja inicial | [Caja diaria](./finanzas/caja-diaria.md) |

---

## Si algo sale mal

- Anotá usuario, organización, fecha, hora aproximada y acción realizada.
- Copiá el mensaje visible si aparece.
- Revisá si el problema se repite al actualizar la página.
- Si enviás captura a soporte, ocultá claves, secretos y datos sensibles.
