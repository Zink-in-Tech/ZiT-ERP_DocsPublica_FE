## Crear pedidos desde texto

Pegá el mensaje de un cliente, por ejemplo desde WhatsApp, y ZinkERP identifica la información necesaria para preparar el pedido.

Antes de abrirlo, podés revisar el contacto y los productos encontrados. El pedido queda listo para controlar y completar en el formulario: no se guarda automáticamente.

**Dónde:** listado de Pedidos o formulario de pedido.

**Cómo usarlo**

1. Copiá el mensaje del cliente.
2. Abrí la opción para importar desde texto.
3. Revisá el contacto y los productos encontrados.
4. Corregí las coincidencias si hace falta.
5. Abrí el pedido y controlalo antes de guardarlo.

:::note Función beta
Esta función se encuentra en beta. Revisá siempre los datos interpretados antes de guardar el pedido.
:::

## Importación asistida de productos

El nuevo asistente permite importar productos desde archivos **CSV o Excel**, relacionar las columnas del archivo con los datos de ZinkERP y realizar la carga por lotes.

**Dónde:** Productos e Importaciones.

**Cómo funciona**

1. Subí el archivo.
2. Indicá qué representa cada columna.
3. Definí los valores necesarios.
4. Revisá la información.
5. Ejecutá la importación por lotes.

:::note Función beta
Durante esta etapa, la importación asistida convive con el importador tradicional.
:::
