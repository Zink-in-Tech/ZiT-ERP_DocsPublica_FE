# Introducción

Bienvenido a la documentación pública de **ZinK ERP**. Aquí encontrarás guías de uso, conceptos del producto y material de referencia.

## Qué encontrarás

- Visión general de la arquitectura y módulos.
- Pasos iniciales para equipos que adoptan el sistema.
- Documentación ampliada conforme publiquemos nuevas versiones.

## Requisitos locales (para colaboradores)

Para previsualizar o compilar este sitio en tu máquina necesitas [Node.js](https://nodejs.org/) **20 o superior**.

```bash
npm install
npm run start
```

El sitio de desarrollo queda disponible en `http://localhost:3000`.
