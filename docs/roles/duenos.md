## Objetivo

Este recorrido está pensado para la persona que necesita entender cómo funciona el negocio dentro de Zink ERP, sin operar necesariamente todas las pantallas todos los días.

El foco está en validar que:

- el sistema esté bien configurado;
- las ventas y compras impacten como corresponde;
- el stock y la caja reflejen la operación real;
- el equipo tenga permisos y procesos claros.

## Señales de alerta frecuentes

- Se vende, pero la caja no refleja el dinero esperado.
- Hay diferencias de stock sin una explicación clara.
- El equipo no puede cobrar o confirmar operaciones por permisos.
- Se emiten precios incorrectos por listas mal configuradas.
- Se intenta usar facturación electrónica sin tener completo el circuito de ARCA.
