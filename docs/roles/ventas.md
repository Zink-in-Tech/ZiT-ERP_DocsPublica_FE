Este recorrido ayuda a quienes trabajan ventas comerciales con etapas, seguimiento del cliente y cierre con cobro inmediato o diferido.

## Qué revisar antes de confirmar una venta

- cliente correcto;
- lista de precio correcta;
- stock suficiente o criterio de validación;
- condición de cobro;
- permiso del usuario para cobrar si corresponde.
