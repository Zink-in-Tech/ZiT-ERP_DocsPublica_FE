Este recorrido ayuda a ordenar el trabajo de depósito para que el stock del sistema se acerque lo máximo posible al stock físico.

## Tareas habituales

### Cuando entra mercadería

- Revisar orden o compra asociada.
- Confirmar cantidades recibidas.
- Registrar la recepción correctamente.

### Cuando hay diferencias

- Evitar "corregir de memoria".
- Registrar ajustes o toma de inventario según el caso.

### Para reposición

- Revisar [Informe Stock crítico](../informes/informe-stock-critico.md).
- Confirmar ubicaciones y stock mínimo por producto.
