## Resumen

La administración concentra los datos maestros que usa todo el ERP: quién compra y vende (contactos), qué se comercializa (productos), quién opera el sistema (usuarios y perfiles) y parámetros fiscales o de precios.

Configurá esto antes de operar a escala.
